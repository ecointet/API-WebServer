## Base URL

```
https://api.cointet.com
```

All endpoints are served over HTTPS. HTTP requests are not supported.

---

## Authentication

The API uses **HTTP Basic Authentication**. Pass your credentials on every request.

```bash
curl -u YOUR_USER:YOUR_PASS https://api.cointet.com/flights
```

<Warning>
Never expose credentials in client-side code. Route requests through your backend.
</Warning>

---

## Endpoints

| Method | Path | Description |
|--------|------|-------------|
| `GET` | `/flights` | List all active flights (optional `?airport=` filter) |
| `GET` | `/flights/{flightCode}` | Full details for a specific flight |

---

## Request parameters

### `GET /flights`

| Parameter | In | Type | Required | Description |
|-----------|----|------|----------|-------------|
| `airport` | query | `string` | No | 3-letter IATA code — filters by origin **or** destination. Pattern: `^[A-Z]{3}$` |

### `GET /flights/{flightCode}`

| Parameter | In | Type | Required | Description |
|-----------|----|------|----------|-------------|
| `flightCode` | path | `string` | Yes | IATA flight identifier. Pattern: `^[A-Z]{2}\d{1,4}$` (e.g. `AF011`, `DL402`) |

---

## Response format

All successful responses return JSON with `Content-Type: application/json`.

### Flight summary (list response)

```json
{
  "total": 2,
  "airport_filter": "CDG",
  "flights": [
    {
      "flightCode":         "AF011",
      "airline":            "Air France",
      "origin":             "CDG",
      "destination":        "JFK",
      "scheduledDeparture": "2026-11-23T08:30:00Z",
      "scheduledArrival":   "2026-11-23T11:50:00Z",
      "status":             "in_flight"
    }
  ]
}
```

### Flight detail (single flight response)

```json
{
  "flightCode":          "AF011",
  "airline":             "Air France",
  "aircraft":            "Airbus A380-800",
  "origin": {
    "iata":    "CDG",

  },
  "destination": {
    "iata":    "JFK",
    "name":    "John F. Kennedy International Airport",

  },
```

## HTTP status codes

| Code | Description |
|------|-------------|
| `200 OK` | Request successful |
| `401 Unauthorized` | Missing or invalid credentials |
| `404 Not Found` | Flight code does not exist |
| `400 Bad Request` | Invalid parameter format (e.g. airport code not 3 uppercase letters) |
| `500 Internal Server Error` | Unexpected server error |

---

## Timestamps

All date-time fields are **ISO 8601 strings in UTC**:

```
2026-11-23T08:30:00Z
```

Fields that may be `null`:

| Field | When null |
|-------|-----------|
| `actualDeparture` | Flight has not yet departed |
| `estimatedArrival` | No estimate available yet |
| `gate` | Gate not yet assigned |
