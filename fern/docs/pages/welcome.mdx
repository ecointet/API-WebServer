<div className="vitrine-section-label">Quick start</div>

```bash title="Your first request"
curl -u user:pass https://api.cointet.com/flights?airport=CDG
```

```bash title="Retrieve a specific flight"
curl -u user:pass https://api.cointet.com/flights/AF011
```

<Note>
All endpoints return `application/json`. Timestamps are ISO 8601 UTC — e.g. `2026-11-23T08:30:00Z`. See the [Quick Start](/quickstart) guide for full examples in curl, Python, and JavaScript.
</Note>
