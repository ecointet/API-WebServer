## Endpoints

<CardGroup cols={2}>
  <Card title="GET /flights" icon="fa-duotone fa-plane" href="/flights-api/get-flights">
    Returns a list of all currently active flights. Filter results by IATA airport code using the `?airport=` query parameter.
  </Card>
  <Card title="GET /flights/{flightCode}" icon="fa-duotone fa-magnifying-glass" href="/flights-api/get-flight-by-flight-code">
    Returns full departure, arrival, aircraft, and status details for a specific flight identified by its IATA code (e.g. `AF011`).
  </Card>
</CardGroup>

## Quick Start

<Steps>
<Step title="Authenticate">

All requests require HTTP Basic Authentication. Pass your credentials with each request:

```bash title="cURL"
curl -u username:password https://api.cointet.com/flights
```

</Step>
<Step title="List active flights">

Fetch all currently tracked flights:

```bash title="All flights"
curl -u username:password https://api.cointet.com/flights
```

Filter by departure or arrival airport:

```bash title="Filter by CDG"
curl -u username:password "https://api.cointet.com/flights?airport=CDG"
```

</Step>
<Step title="Retrieve flight details">

Use the IATA flight code to get full details — times, gate, terminal, delay:

```bash title="Flight AF011"
curl -u username:password https://api.cointet.com/flights/AF011
```

</Step>
</Steps>

## Base URL

```
https://api.cointet.com
```

<Note>
All endpoints return `application/json`. Date-time values are ISO 8601 UTC strings (e.g. `2026-11-23T08:30:00Z`).
</Note>
