The `status` field appears on both the list (`GET /flights`) and detail (`GET /flights/{flightCode}`) responses.
It is an enum of eight values that map to the standard IATA operational lifecycle of a flight.

## Status lifecycle

A flight typically progresses through the following sequence:

```
scheduled → boarding → departed → in_flight → landed → arrived
```

At any point before `departed`, a flight may transition to:

```
* → delayed
* → cancelled
```

<Note>
A `delayed` flight may still board and depart — it retains the `delayed` status to reflect the original schedule deviation. The `delayMinutes` field is the authoritative value for delay quantification.
</Note>

## In your code

Filter the response to only show flights currently in the air:

```javascript title="JavaScript — filter in-flight"
const { flights } = await (await fetch(
  "https://api.cointet.com/flights",
  { headers: { Authorization: "Basic " + btoa("user:pass") } }
)).json();

const airborne = flights.filter(f => f.status === "in_flight");
```

```python title="Python — group by status"
import requests
from collections import defaultdict

r = requests.get(
    "https://api.cointet.com/flights",
    auth=("user", "pass"),
)
by_status = defaultdict(list)
for flight in r.json()["flights"]:
    by_status[flight["status"]].append(flight)
```
